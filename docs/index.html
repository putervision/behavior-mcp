set_parameters

🛡️ 5-Layer Behavioral Safety Stack

Production-grade execution guardrails guaranteeing stability, browser thread safety, and immediate emergency disengagement.

⏱️ 1. Token Bucket Rate Limiting

Strict frequency guards enforce tick intervals up to 60Hz. Burst dampening prevents event-loop starvation and runaway browser DOM manipulation spikes.

🔍 2. Stuck State Detection

Heuristic cycle detectors and stationary watchdogs identify repeated failure sequences, deadlocked nodes, or idle loops within 500ms, triggering recovery branches.

💀 3. Dead-Man Watchdog

Constant client heartbeat requirement. If a communication gap or unhandled crash exceeds 2000ms, all active keys, mouse buttons, and browser inputs disengage immediately.

🚪 4. Policy Gate Verification

All action payloads pass deterministic security boundary checks (domain whitelisting, prohibited selector blacklists, destructive mutation guards) before entering the tick queue.

📜 5. SHA-256 Merkle Audit Trail

Every tree definition, trigger activation, parameter hot-swap, and abortion event is cryptographically hashed and chained into a tamper-evident audit log for post-mortem forensics.

🚀 Quickstart & Client Integration

Integrate behavior-mcp into your AI coding assistant with zero external dependencies.

1. Global Installation

Install globally via npm for CLI and server usage:

npm install -g @putervision/behavior-mcp

2. Client Configurations

Claude Code CLI

claude mcp add behavior-mcp -- npx -y @putervision/behavior-mcp

Cursor IDE (.cursor/mcp.json)

{ "mcpServers": { "behavior-mcp": { "command": "npx", "args": ["-y", "@putervision/behavior-mcp"] } } }

Gemini CLI

gemini mcp add behavior-mcp npx -y @putervision/behavior-mcp

3. Health & Runtime Verification

Verify installation and audit runtime database health:

behavior-mcp doctor
