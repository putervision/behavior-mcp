# CLI Usage: behavior-runtime-mcp

Command-line reference for `@putervision/behavior-runtime-mcp`.

```bash
# Start MCP server on stdio transport
behavior-runtime-mcp run

# Initialize workspace, database, seed behaviors, and agent rules
behavior-runtime-mcp init [--project <slug>]

# Run diagnostic health checks
behavior-runtime-mcp doctor

# Inspect active executions and triggers
behavior-runtime-mcp inspect

# Verify SHA-256 Merkle audit chain
behavior-runtime-mcp audit
```
